# No-MCP / No-Custom-Action Declaration

This Stage 5 KV Sermon Plugin package introduces no MCP server, custom external action, hook, datastore, or publishing integration.

The required behavior is implemented through:

- `kv-sermon-builder` core Skill;
- nine validated supporting Skills;
- bundled core sermon references;
- standard ChatGPT plugin/Skill mechanics.

External tooling may be reconsidered only when a later approved requirement cannot be handled through these layers.
