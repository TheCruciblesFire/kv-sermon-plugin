# Example Style Notes

Use the attached Teaching Packet Builder materials and prior handout examples as style references.

## Preferred Output Feel

- One page in final document form.
- Title and subtitle at the top.
- Main Scripture reference visible.
- One clear Big Idea.
- Three to five compact teaching movements.
- Minimal reflection prompts.
- One concrete response step.

## When Using Fill-in Blanks

The prior handout examples used sparse blanks in the big idea and movement bullets. Preserve that restraint.

Student version:

`God's presence is no longer confined to a __________.`

Answer-key version:

`God's presence is no longer confined to a __________ (place).`

## Do Not Drift Into

- full workbook sections
- long manuscript excerpts
- leader notes
- excessive blanks
- answer guidance in the student copy
- new theological material not present in the source
