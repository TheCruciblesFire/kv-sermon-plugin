# Claim Categories and Support Labels

## Source Categories

| Category | Meaning |
|---|---|
| Direct biblical text | Explicitly stated in the controlling passage. |
| Immediate context | Supported by nearby passage context. |
| Canonical support | Supported by broader Scripture synthesis. |
| User-supplied material | Comes from the user's notes, handoff, sermon, outline, or document. |
| Knowledge-file framework | Comes from GPT-specific framework, tone, theology, or workflow files. |
| External source | Comes from web research, commentary, article, book, dataset, or other outside source. |
| Original-language claim | Based on Greek, Hebrew, morphology, syntax, or lexical data. |
| Historical / cultural background | Background claim requiring source support. |
| Reasonable inference | Not directly stated, but responsibly inferred from source material. |
| Speculation | Possible but weakly supported or not demonstrable from the source base. |
| Generated synthesis | The GPT's own organization or summary of multiple sources. |
| Unsupported claim | Claim currently lacking adequate support. |

## Support-Level Labels

| Label | Definition |
|---|---|
| Directly supported | Clearly grounded in the named source. |
| Contextually supported | Supported by immediate or broader context. |
| Reasonable inference | Plausible and responsibly framed. |
| Needs citation | May be true but requires external or specific support. |
| Overstated | Contains more certainty than the source allows. |
| Unsupported | Not adequately supported by supplied sources. |
| Speculative | Possible but should not be presented as fact. |
| Misattributed | Attributed to the wrong source category. |

## Common Correction Actions

- Add a source statement.
- Soften the wording.
- Remove the claim.
- Cite or name the external source.
- Move the claim to an inference category.
- Mark the claim as framework influence.
- Verify externally before use.
- Route to Passage Faithfulness / Theological Overreach Check.
