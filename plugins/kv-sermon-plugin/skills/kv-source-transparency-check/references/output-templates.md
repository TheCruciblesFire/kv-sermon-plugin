# Output Templates

## Mode A: Brief Source Statement

Use this when the main output only needs a short disclosure.

```markdown
## Source Base
This output is based on [primary source], with support from [user-supplied material / knowledge files / prior handoff if applicable]. [No external sources were used / External sources used are named in the response]. Interpretive and application statements are presented as synthesis unless directly tied to the cited passage.
```
