# Study to Sermon Handoff Template

Use this template when converting Study Engine material into a Sermon Builder handoff.

## KV Sermon Builder Handoff

### 1. Source Base
- **Controlling passage:** [passage]
- **Primary source material:** [Supplied KV Study Engine passage study / sermon-prep output / inductive study / user notes]
- **Scripture translation noted in source:** [CSB / other / not specified]
- **Additional sources named:** [list exactly as supplied, or state “No external sources were named.”]
- **Named / cited sources preserved from Study Engine:** [list source names, file names, commentary names, lexical tools, user-supplied documents, and citation notes exactly as supplied; if none, state “No external sources were named.”]
- **Source transparency note:** [brief note; distinguish Scripture, user-supplied material, framework influence, external sources, and generated synthesis]

### 2. Passage Burden to Preserve
[Concise statement of the central burden from the study. Do not invent a new sermon thesis.]

### 3. Passage Flow / Movement
Provide only the passage movement needed for sermon preparation. Use short phrases, not a full sermon outline.

- [Text unit 1]: [movement]
- [Text unit 2]: [movement]
- [Text unit 3]: [movement]

### 4. Major Textual Claims
Classify support level for each major claim.

| Claim | Support Level | Notes |
|---|---|---|
| [claim] | Direct textual claim / Strong contextual inference / Responsible biblical-theological synthesis / Pastoral application lane / Caution-do not overstate | [brief note] |

### 5. Sermon-Ready Direction
Give direction Sermon Builder can use without producing the sermon.

- **Possible sermon burden:** [one sentence]
- **Possible aim:** [what hearers should see, believe, repent of, trust, or obey]
- **Possible title direction:** [optional, 1-3 options]
- **Preaching angle to consider:** [brief]
- **Application lanes:** [brief, passage-tethered]

### 6. Interpretive Cautions
List cautions from the study and any obvious handoff risks.

- [caution]
- [caution]

### 7. Theological Boundaries
Name what may be said, what should be qualified, and what should not be made controlling.

- **Safe to emphasize:** [items]
- **Use with qualification:** [items]
- **Do not overstate or force:** [items]

### 8. Gospel / Canonical Connection
State only a responsible connection, not a forced sermon conclusion.

- **Local passage first:** [how the passage itself carries the burden]
- **Canonical / gospel trajectory:** [brief, qualified synthesis]
- **Caution:** [what not to flatten or force]

### 9. Recommended Sermon Builder Instructions
Provide concise instructions for the receiving Sermon Builder GPT.

- Use this handoff as the controlling source.
- Keep the sermon centered on [passage].
- Preserve the passage burden: [brief].
- Distinguish textual claims from inference and synthesis.
- Preserve the cautions and theological boundaries above.
- Do not create slides, devotionals, packets, or course assets unless separately requested.

### 10. Optional Quality Checks Before Sermon Build
Include only checks that are actually needed.

- Source transparency check: [needed / not needed / already clear]
- Passage faithfulness check: [needed / not needed / recommended for specific claim]
- Scripture formatting check: [needed / not needed]
- Multi-asset throttle: [needed only if downstream assets are requested]
