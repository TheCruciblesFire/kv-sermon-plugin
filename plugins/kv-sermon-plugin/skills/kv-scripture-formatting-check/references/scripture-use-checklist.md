# Scripture Use Checklist

## Translation
- Is the translation named when exact Scripture is quoted?
- Is CSB used by default unless another translation is requested?
- Are mixed translations clearly labeled and intentional?

## Quotation vs Summary
- Are exact quotations visually distinct?
- Are summaries labeled as summaries?
- Are paraphrases free from quotation marks unless exact text is supplied?

## Reference Precision
- Are references specific enough?
- Are verse ranges consistent?
- Are broad references intentional?
- Are supporting references selective rather than overwhelming?

## Distribution Readiness
- Is this for public, web, app, LMS, PDF, workbook, or print use?
- If CSB is quoted, is approved attribution present?
- If attribution wording is unavailable, use a placeholder rather than inventing it.

## BLB Links
- Is the visible reference preserved?
- Is Markdown link syntax valid?
- Are exact links supplied or verified?
- If uncertain, use a verification placeholder rather than inventing a URL.
