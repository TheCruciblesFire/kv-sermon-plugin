# Failure Modes and Corrections

| Failure Mode | Correction |
|---|---|
| Producing every requested asset in full | Produce the primary asset only plus brief handoff notes. |
| Creating downstream assets before source approval | Recommend finalizing the source or master handoff first. |
| Treating handoff notes as finished assets | Label handoff notes clearly and keep them brief. |
| Rewriting source material while adapting | Preserve the source burden and mark any changes. |
| Mixing student and leader content | Route to Student Packet Builder or use a leader/student separation workflow. |
| Turning sermon into lesson without redesign | Route to Course Builder or provide a conversion brief. |
| Turning devotional into sermon | Preserve devotional genre or route to Sermon Builder only if requested. |
| Adding unsupported theology in downstream notes | Recommend passage-faithfulness and source-transparency checks. |
| Omitting production order | End with a clear build sequence. |
| Treating a broad bundle request as permission for all assets | State the controlling output layer and stage the work. |
