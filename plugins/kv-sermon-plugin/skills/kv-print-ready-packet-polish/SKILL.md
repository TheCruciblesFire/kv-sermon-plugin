# KV Print-Ready Packet Polish

## Core Purpose

Polish an already-developed ministry packet or learner/leader resource for clean print or PDF distribution without changing the controlling teaching burden. Treat this as final production cleanup and quality control, not content creation.

## Operating Rules

- Preserve the source meaning, Scripture focus, theological movement, and pastoral tone.
- Do not create new lessons, new exegesis, new sermon manuscripts, new devotionals, or new student activities unless explicitly requested.
- Do not expand sparse teaching into a full packet. Polish what exists.
- Keep student-facing material, leader-facing notes, and answer-key content clearly separated.
- Retain blanks, response spaces, answer cues, and facilitator notes according to their intended audience.
- Flag substantive theological, source, or passage-faithfulness concerns instead of silently rewriting them.
- Use plain, printable formatting. Avoid design complexity that would make the resource harder to print, photocopy, or use in a group.

## Inputs to Accept

Accept completed or near-completed drafts such as:

- student workbook
- one-page handout
- sermon listening guide
- discussion sheet
- leader or facilitator guide
- devotional packet
- course lesson packet
- ministry worksheet bundle
- answer-key version of a student resource

If the source is incomplete, still perform a polish pass on the available material and state what could not be verified.

## Standard Polish Workflow

### 1. Identify the Resource Type and Audience

Name the apparent resource type and audience before revising:

- Student-facing packet
- Leader/facilitator guide
- Sermon listening guide
- One-page handout
- Devotional packet
- Course worksheet
- Answer key
- Mixed packet with multiple audiences

If the packet mixes audiences, separate or label sections rather than blending them.

### 2. Preserve the Content Layer

Maintain the original teaching structure unless the user asks for restructuring. Acceptable edits include:

- tightening headings
- correcting inconsistent labels
- clarifying instructions
- smoothing transitions
- standardizing prompt wording
- moving answer guidance into leader or answer-key sections
- removing accidental duplication
- repairing obvious formatting drift

Avoid adding new biblical claims, interpretive claims, illustrations, applications, or cross-references unless explicitly asked.

### 3. Apply Print-Ready Formatting Standards

Check and polish:

- title block consistency
- section heading hierarchy
- lesson/session numbering
- page-break logic
- table readability
- response-space placement
- line spacing and margin friendliness
- repeated headers or footers
- Scripture reference formatting
- answer-key labeling
- leader-note labeling
- consistent use of bold, italics, bullets, numbering, and indentation

For worksheet-style material, keep response spaces usable. When a response space is already inside a table cell, do not add long blank lines inside that same cell; leave clean blank space or a short prompt instead.

### 4. Check Audience Separation

Use these labels when needed:

- **Student Version**
- **Leader Guide**
- **Answer Key**
- **Facilitator Notes**
- **Do Not Include in Student Copy**

Remove or relocate leader-only material from student-facing sections. Remove or relocate answers from non-answer-key student copies.

### 5. Check Scripture and Source Handling

Perform a light source-preservation review:

- Keep Scripture references attached to the relevant claim or prompt.
- Do not turn paraphrases into quotations.
- Do not add translation labels unless the source supplies them or the user asks.
- If exact Scripture quotations appear, preserve wording and attribution unless the user asks for standardization.
- Flag missing translation labels, mixed translation signals, unsupported historical claims, or source-dependent claims that need verification.

For deeper Scripture formatting or passage-faithfulness review, recommend those checks rather than trying to perform a full audit inside this polish pass.

### 6. Check Pedagogical Usability

Improve practical usability without overbuilding:

- make instructions direct and age/audience appropriate
- ensure questions are answerable from the provided material
- remove redundant prompts
- align response spaces with expected answer length
- keep discussion questions open enough for group use
- avoid turning every section into an activity
- keep leader prompts flexible, not scripted

### 7. Produce One of Three Output Modes

Choose the mode that best matches the user request.

#### Mode A: Polished Draft

Use when the user asks to clean up, revise, or make the packet print-ready. Return the revised packet text with headings and clean formatting.

#### Mode B: QC Report Only

Use when the user asks to audit, review, or identify problems. Return findings without rewriting the full packet.

#### Mode C: Polished Draft + QC Notes

Use when the user asks for final polish and wants to know what changed. Return the polished packet first, then concise QC notes.

## Required QC Categories

When giving QC notes, use only categories that apply:

1. **Audience Separation**
2. **Print Layout / Formatting**
3. **Scripture Formatting**
4. **Source Preservation**
5. **Theological / Passage-Faithfulness Flags**
6. **Learner Usability**
7. **Answer Key / Leader Notes**
8. **Remaining Items Before Export**

## Final Output Standards

- Use clean markdown that can be transferred into a document editor.
- Keep headings consistent and scannable.
- Preserve the user’s wording where it is already clear and faithful.
- Do not bury important warnings in long commentary.
- If no major issues are found, say so directly.
- If a print-ready document file is requested, follow the relevant document/PDF creation instructions available in the environment; this Skill governs the polish standards, not the file-conversion mechanics.

## Concrete Test Prompts

Use these prompts to test the Skill:

1. “Polish this completed student workbook for print distribution. Do not add new content. Keep leader notes out of the student copy.”
2. “Audit this sermon listening guide for print readiness and answer-key separation. Give me QC notes only.”
3. “Clean up this leader guide so it is ready to export as a PDF. Keep the answer guidance flexible, not scripted.”
4. “Review this mixed packet and separate anything that belongs only in the leader version.”
5. “Make this devotional worksheet packet more print-ready without changing the theology or adding new prompts.”
6. “Final QC this course lesson packet before I turn it into a PDF. Watch for formatting drift, response-space problems, and Scripture-label issues.”
