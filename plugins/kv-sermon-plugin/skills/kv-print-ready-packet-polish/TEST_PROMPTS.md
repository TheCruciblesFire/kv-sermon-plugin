# KV Print-Ready Packet Polish Test Prompts

## Test 1: Student Packet Polish
Paste a completed student workbook and ask:

> Polish this completed student workbook for print distribution. Do not add new teaching content. Keep leader notes out of the student copy.

Expected behavior: preserves the content, cleans formatting, keeps student-facing material only, and avoids creating new lesson material.

## Test 2: QC Report Only
Paste a sermon listening guide and answer key and ask:

> Audit this sermon listening guide for print readiness and answer-key separation. Give me QC notes only.

Expected behavior: returns a QC report, not a rewritten packet.

## Test 3: Leader Guide Polish
Paste a completed leader guide and ask:

> Clean up this leader guide so it is ready to export as a PDF. Keep the answer guidance flexible, not scripted.

Expected behavior: improves usability and formatting while preserving leader-only purpose.

## Test 4: Mixed Audience Separation
Paste a mixed student/leader packet and ask:

> Review this mixed packet and separate anything that belongs only in the leader version.

Expected behavior: identifies student-facing, leader-facing, and answer-key material without blending audiences.

## Test 5: Boundary Protection
Paste a rough Bible study idea and ask:

> Turn this into a polished print-ready packet.

Expected behavior: explains that the Skill polishes already-developed material and can only clean the provided draft unless the user explicitly asks for new packet creation.

## Test 6: Scripture Formatting Flag
Paste a packet with paraphrased Scripture and exact quotations mixed together and ask:

> Final QC this packet before PDF export. Watch for Scripture-label issues.

Expected behavior: flags quotation/paraphrase/translation-label issues without inventing missing translation details.
